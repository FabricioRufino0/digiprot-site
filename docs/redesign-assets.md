# Assets do redesign DIGIPROT

## Origem

- Logo: `assets/digiprot-logo.png`, copiado integralmente para `public/assets/identity/digiprot-logo.png`. O original não foi alterado.
- Projetos reais: capturas próprias das páginas públicas Nandices Confeitaria e Sobradinho Injeção Diesel, informadas pelo usuário como seus projetos. Capturas de 1440 × 960 e 390 × 844, em 02/10/2026.
- Conceitos: capturas dos quatro exemplos da versão anterior. Permanecem exemplos conceituais, sem métricas, depoimentos ou vínculo com clientes.
- Anel de foco: SVG geométrico autoral e editável. Gradientes restritos ao material, com arestas coral e turquesa. A imagem gerada aprovada foi usada apenas como referência.
- Fontes: Archivo e Manrope, distribuídas por Fontsource e hospedadas localmente no build, sob SIL Open Font License.
- Ícones: Lucide, apenas direções, menu e formatos de tela.

## Catálogos consultados

- Watermelon Accordion 1: código obtido pelo MCP em `https://ui.watermelon.sh/components/accordion`. A composição de cabeçalhos expansíveis foi adaptada para os serviços, com títulos e resumos DIGIPROT. O conteúdo usa `details` e `summary` nativos, abertura animada por CSS e suporte a movimento reduzido, sem dependências adicionais.

- Watermelon MCP: comparados Discrete Tabs, Fluid Tabs e Continuous Tabs. Inspecionado o código de Discrete Tabs. O brilho automático, o foco duplicado e a animação de largura foram descartados. A página usa a composição acessível de abas do shadcn/Base UI com transição de conteúdo própria.
- shadcn MCP/CLI: primitivo Tabs de Base UI instalado via CLI e adaptado para tokens DIGIPROT. Corrigida a importação de utilitário do registro; removidas classes de aparência e `transition-all`.
- Skiper UI: catálogo gratuito consultado; nenhum código ou asset copiado. Sem dependência de Lenis ou componente Pro.
