# Prévias temporárias de sites

Esta pasta contém apresentações visuais em PDF para possíveis clientes da DIGIPROT. Cada PDF foi desenhado para parecer uma página de site, com imagens ilustrativas e conteúdo conceitual. Disponibilidade, preços, horários e serviços devem ser confirmados com cada negócio antes de publicar um site real.
